Everything an electrical engineer needs

From schematic capture to panel layout, from BOM to live PLC monitoring.

IEC / JIC / IEEE / NFPA symbols

Over 75 built-in symbols across four standards, plus a custom Symbol Builder and DWG block library import.

Automatic wire colouring

Four modes: IEC 60757, DC polarity, AC phase, default. Applied project-wide from wire numbers.

12-check wiring verification

Dangling pins, dead-end wires, duplicate tags, orphan contacts, power/signal shorts, unconnected PLC channels — all caught.

PLC I/O & backplane drawings

Rack / slot / channel configuration. Backplane auto-generation. Live Modbus TCP monitoring.

Panel layout with 2-way sync

3D isometric panel drawing linked to the schematic. Click either side, the other highlights.

Reports that ship

BOM, wire from/to, terminal strips, cable schedules, cross-references, PLC I/O tables. Excel + PDF + DXF.

Multi-language UI

English, Português, Español, Français. Add more by dropping a JSON file into the app's lang/ folder.

Open and scriptable
