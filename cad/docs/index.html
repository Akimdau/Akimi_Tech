Installation

  1. Click the download button above.
  2. Double-click AkimitechCAD_Setup_13.0.0.exe.
  3. Accept the UAC prompt.
  4. Walk the wizard (defaults work).
  5. Launch from the Start menu.

No Python or other software is required. Works on a clean Windows 10 or 11 machine.

Quick start

  1. File → New Project
  2. IEC tab → Contactor Coil → click on the canvas
  3. Wires tab → Wire → click from pin to pin
  4. AkimiTech tab → Colour → IEC 60757 → Apply Now
  5. AkimiTech tab → Verify to check the design

Command line aliases

Type an alias into the command line and press Enter.

  • Draw: L C REC A PL T
  • Modify: TR EX F CHA O MI
  • Wire: WID, AWNS
  • Colour: WCI, WCDC, WCAC, WCOL
  • Verify: VERIFY or WV
  • Reports: BOM NET XR WR PLC
  • File: W, OPEN, PDF, DXF

Adding manufacturer parts

Open AkimiTech tab → Catalog → Import CSV. Your file must have these headers:

mpn,manufacturer,description,symbol_name,category,price,datasheet_url

Set symbol_name to match the AkimiTech symbol you want the part attached to (e.g. Contactor Coil, Fuse). Once imported, the part appears in the Select part… dialog and is carried through to the BOM.

Troubleshooting

  • App doesn't launch: confirm Windows 10 or 11, 64-bit.
  • Antivirus warning: the installer is unsigned. Click "More info" → "Run anyway".
  • DWG import fails: the file must be a .dxf with named BLOCK definitions.
  • Live PLC doesn't connect: install pymodbus via pip install pymodbus, then reopen the dialog.
